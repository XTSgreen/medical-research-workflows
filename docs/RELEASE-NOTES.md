# Research plugins preview

This preview publishes the four MIT plugin cores, dsh bundle adapters, original fictional examples, tests and the separate Med-Lab Mini source. It preserves the existing workflow-starter tutorial.

| Package | Version | Included flow |
| :-- | :-- | :-- |
| dsh-literature-radar | 0.1.5 | Three source adapters, DOI-list filtering, reports, read-only model context and persistent lifecycle controls |
| dsh-paper-autopsy | 0.1.3 | Physical PDF pages, five-column cards, source excerpts and Crossref metadata checks |
| dsh-review-copilot | 0.1.4 | Review workspace, five MIT P1 templates, read-only context, draft and author-confirmation workflow |
| dsh-clinic-writer | 0.1.4 | Source units, X2 import, section drafts and supplied journal-rule adaptation |
| med-lab-mini | 0.1.1 | Local data exploration, explicit method approval, four fixed statistical methods and reports |

The four npm package names identify the source packages; npm publication has not yet completed. Use the archives attached to this GitHub preview or build them locally. Installing an archive with npm installs its declared dependencies and normally needs registry access. Keeping a dsh host alive is required for background radar jobs.

No real model-quality claim is made. Review/writer structure and evidence checks do not prove scientific correctness, clinical benefit, completed experiments or author identity. See VALIDATION.md and each package README for the actual supported scope and pending checks.

These documentation patches replace private-workspace verification/install paths with commands available in the public checkout. Runtime algorithms are unchanged; package versions were incremented for the corrected distributions.
